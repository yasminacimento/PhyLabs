## 🚀 Sobre o Projeto

O **PhyLabs** é um projeto criado para facilitar o aprendizado de física através de módulos práticos e exercícios interativos.

### 🛠️ Tecnologias Utilizadas

* **Design / UI:** Figma
* **Front-end:** Flutter, HTML/CSS.
* **Back-end:** Python, Java e Dart.
